# astronaut-game

«Игровая орбита» - набор браузерных образовательных мини-игр на космическую тематику:

- **"Одень космонавта"**: сборка скафандра космонавта с помощью перетаскивания объектов;
- **"Запусти ракету"**: сборка ракеты "СОЮЗ" и отброс ее деталей после запуска с помощью перетаскивания объектов;
- **"Космическая викторина"**: классическая викторина с тремя уровнями сложности;
- **"Угадай спутник"**: по внешнему и подсказкам нужно определить тип спутника, с выбором ответа из представленных.

### Стек
- **HTML5**;
- **CSS3**;
- **JavaScript**: Canvas 2D.
